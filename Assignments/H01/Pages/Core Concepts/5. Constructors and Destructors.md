# Constructors and Destructors in C++
Constructors and destructors are special member functions in C++ that manage the lifecycle of an object.

## Constructors
A _constructor_ is a special member function used to initialize objects of its class.

## Destructors
A destructor is a member function that is invoked automatically when an object goes out of scope or is explicitly destroyed.

## Key Differences (Constructor vs Destructor)
| Feature | Constructor | Destructor |
| -- | -- | -- |
| Purpose | Initializes the object | Cleans up and releases resources |
| Execution Order | Base class first, then derived class | Derived class first, then base class |
| Parameters | Can have arguments (allows overloading) | Cannot have arguments |
| Overloading | Supported | Not supported |
| Inheritance | Cannot be inherited | Cannot be inherited |
