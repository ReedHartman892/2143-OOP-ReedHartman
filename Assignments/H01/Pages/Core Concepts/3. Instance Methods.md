# Methods in C++
Methods, or "member functions" are functions that belong to a class and define the behavior of its objects.

There are several types of methods in ```C++``` that a class can have, but this section will focus on the type of member function known as "instance member functions", or an instance method. To read about other types of methods, see the section titled "further reading"

### Method Examples
``` cpp
class Example {
    int output(){} // instance example
    static void print(){} // static example
    virtual void run_time(){} // virtual example
    Example(){} // special example; a constructor
};
```

### Definition of an Instance Member Function
These are standard functions that operate on an object or instance of a class, and have access to all data members regardless of access level. They have an implicit ```this``` pointer that points to the specific object calling them.

#### Key Characteristics
- **Object-Specific:** They operate on the data (instance variables) of the specific object that invokes them.
- **The `this` Pointer:** Every instance method has access to an implicit this pointer, which holds the memory address of the calling object.
- **Dot/Arrow Operator:** They are called using the dot operator (`.`) for objects or the arrow operator (`->`) for pointers to objects.
- **Encapsulation:** They are often used to provide a public interface for accessing or modifying private data members, ensuring data integrity. 

### Why It Matters
1. **Access to Object State:** The primary purpose of an instance method is to interact with an object’s instance variables. 
2. **Encapsulation and Data Integrity:** Instance methods provide a controlled interface for interacting with an object's internal data. 
3. **Enabling Polymorphism:** Instance methods are required for dynamic binding, which is the core of polymorphism in C++. 
4. **Code Organization and Readability:** Grouping functions with the data they operate on makes code more intuitive. 

### Common Mistakes
1. **Forgetting `const` Correctness:** A very frequent mistake is failing to mark instance methods as `const` when they do not modify the object's state. 
2. **Missing Virtual Destructors in Base Classes:** When using inheritance and polymorphism, forgetting to declare the base class destructor as virtual is a major pitfall. 
3. **Calling Virtual Methods in Constructors or Destructors:** Calling a `virtual` method inside a constructor or destructor doesn't behave as many expect.
4. **Returning References to Local Objects:** Instance methods sometimes return data by reference to save on copying costs, but this can be dangerous if the data is local.
5. **Passing `this` to Asynchronous Callbacks:** When an instance method passes a pointer or reference of the current object (`this`) to a callback or another thread, it risks lifetime issues. 
6. **Misunderstanding `override` and Overloading:** Modern C++ introduced the `override` keyword to prevent subtle naming bugs.
