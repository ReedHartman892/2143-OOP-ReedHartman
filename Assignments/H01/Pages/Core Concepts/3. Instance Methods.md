# Methods in C++
Methods, or "member functions" are functions that belong to a class and define the behavior of its objects.

There are several types of methods in ```C++``` that a class can have, but this section will focus on the type of member function known as "instance member functions", or an instance method. To read about other types of methods, see the section titled "further reading"

### Method Examples
``` cpp
class Example {
    int output(){} // instance example
    static void print(){} // static example
    virtual void run_time(){} // virtual example
    Example(){} // special example; a constructor
};
```

### Definition of an Instance Member Function
These are standard functions that operate on an object or instance of a class, and have access to all data members regardless of access level. They have an implicit ```this``` pointer that points to the specific object calling them.
