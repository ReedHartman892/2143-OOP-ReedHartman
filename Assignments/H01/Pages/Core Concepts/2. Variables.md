# Variables in C++
A variable is a named storage location in a computer's memory that holds data and can be modified during program execution.

## Member Variables
    Member variables are variables (also known as data members or fields) declared within a class definiton, but outside any member function. They represent the state or properties of an object instantiated from that class.

### Types of Member Variables
 - Instance Variables (Non-Static)
 - Class Variables (Static)

---------------------------------------------------------

## Instance Variables
    Instance Variables are (specifically) non-static member variables declared within a class definition outside of any method, constructor, or block.
    
    Each object gets its own separate copy of their class' instance variable, and their lifespan is tied to the object they belong too.
    
    (If the object is deleted, their variables go too.)

### Common Mistakes

<details>
<summary>Click to see code example for "Instance Variables 'Leaving Variables Uninitialized'"</summary>

``` cpp
// bad code example
class Car {
    string model; // class type
    double value; // primitive type
    const double depreciation_value; // const member

    public:
    Car(){}; // default constructor (evil)
};
```
 - default constructors will initalize primitive types (```int```, ```double```, ```char*```, ```bool```) with unpredictable junk data. This is the likely culprit behind most "mysterious" bugs you might get.
 - class members will have their own default constructors called, this is technically okay. model in this case will just be an empty string
 - const members must be initialized on declaration, or the code will fail to compile. In this case, this code won't compile because depreciation_value has no declared value.

``` cpp
// better code example
class Car {
    string model; // class type
    double value; // primitive type
    const double depreciation_value; // const member

    public:
    Car() : value(0.00), depreciation_value(0.10){}; // default constructor (no junk data)
};
```
 - The above code better initializes all variables by leaving no instances of junk data.
 - initalizing the string in this case is optional, given it will automatically obtain a empty string as a class member.

### Best Practices (summarized)
1. Use getters and setters in your class definiton. Never directly access.
2. Always initialize all variables of a class within its constructor.

## Class Variables (Static Member Variables)
    A special data member that is shared by all instances (objects) of a class. Kind of like global variables.

    There is only one copy of the static variable for the entire class, regardless of how many objects are created.

### Characteristics

 - Scope & Access: Accessed by using the class name and the scope resolution operator ```( :: )```, even if no objects of the class have been created. Like other members, they obey specifiers (public, private, protected)

 - Initialization: Initalized once the program's ```main()``` function starts, and are only destroyed when the program terminates.

```Example 1: Traditional method of static member initialization```
``` cpp
class Car {
    string model; // class type
    double value; // primitive type
    static int total_cars; // static type, declaration inside class

    public:
    // assume getters/setters are provided
    Car() {
        total_cars++;
    }
}

// definition and initialization outside the class.
int Car::total_cars = 0;

int main(){
    Car car1();
    Car car2();
    Car car3();

    std:cout << "Car count: " << Car::total_cars << std::endl; // output test
    return 0;
}
```
``` output
Output:
Car count: 3
```

```Example 2: Modern (C++17) method using the inline method to initialize static members```
``` cpp
class Configuration {
public:
    // Defined and initialized inside the class using 'inline'
    static inline std::string appName = "MyApplication";
    static inline int maxRetries = 5;
};

int main() {
    // Accessing the inline static variables
    std::cout << "App Name: " << Configuration::appName << std::endl;
    std::cout << "Max Retries: " << Configuration::maxRetries << std::endl;
    return 0;
}
```
``` output
App Name: MyApplication
Max Retries: 5
```

2. Forgetting the Definition Outside the Class: You must define non-const static member variables outside the class declarion in a single translation unit.
   - The definition must occur in exactly one ```.cpp``` file.
   - You can also use the inline keyword to define and initialize static members directly within the class declaration, removing  the need for a separate ```.cpp``` definiton
   - ```static const``` integral or enumeration types/members can often be initialized inside the class w/ou an external definition, unless they are ODR-used (taken address).

#### Ways to Access Non-Static Members

```1. Pass an object as a Parameter```
``` cpp
class MyClass {
public:
    int value = 10;
    static void myStaticFunc(MyClass& obj) {
        // Accessing non-static member 'value' through the passed instance
        std::cout << obj.value; 
    }
};
```

```2. Create a New Instance Inside the Function```
``` cpp
static void myStaticFunc() {
    MyClass tempObj;
    tempObj.value = 20;
}
```

</details>

3. Accessing Non-Static Members in Static Functions: aka trying to use a ```this``` pointer to call to a class variable: Minor mistake, but it may happen at one point. Class variables can't use a this variable since they aren't object-specific.

4. Creating Global State: Class variables essentially create global state, which can make code difficult to reason about as widely separated parts of the code can influence the variable.


### Best Practices
1. Use class variables for turly class-wide data (like a total instance count)
2. Use class variables for utility functions that don't depend on object state.
3. Capitalize the names constant and static members to distinguish them.
