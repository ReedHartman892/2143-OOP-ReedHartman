# Encapsulation in C++
Involves bundling data (attributes) and the functions (methods) that operate on data into a single unit, typically a class. It serves as a protective shield that prevents direct external access to an object's internal state.

#### Encapsulation mechanisms include:
 - __Access Specifiers__: `private`, `protected`, `public`
 - __Getters and Setters__: used to safely access and modify `private` data.
 - __Data validation__: enable validation logic, ensuring only valid data updates the object's state.

### Problems That Encapsulation Solves
 - __Maintainability__:  Encapsulation simplifies debugging and testing by organizing code into mdoular units.
 - __Flexibility__:  Encapsulation allows internal implementation changes without breaking external code dependency.
 - __Data Security__:  Encapsulation restricts direct, unauthorized access to internal class members.
