# Variables in C++
A variable is a named storage location in a computer's memory that holds data and can be modified during program execution.

## Member Variables
    Member variables are variables (also known as data members or fields) declared within a class definiton, but outside any member function. They represent the state or properties of an object instantiated from that class.

### Types of Member Variables
 - Instance Variables (Non-Static)
 - Class Variables (Static)

---------------------------------------------------------

## Instance Variables
    Instance Variables are (specifically) non-static member variables declared within a class definition outside of any method, constructor, or block.
    
    Each object gets its own separate copy of their class' instance variable, and their lifespan is tied to the object they belong too.
    
    (If the object is deleted, their variables go too.)

### Common Mistakes

<details>
<summary>Click to see code example for "Instance Variables 'Leaving Variables Uninitialized'"</summary>

``` cpp
// bad code example
class Car {
    string model; // class type
    double value; // primitive type
    const double depreciation_value; // const member

    public:
    Car(){}; // default constructor (evil)
};
```
 - default constructors will initalize primitive types ```(int, double, char*, bool)``` with unpredictable junk data. This is the likely culprit behind most "mysterious" bugs you might get.
 - class members will have their own default constructors called, this is technically okay. model in this case will just be an empty string
 - const members must be initialized on declaration, or the code will fail to compile. In this case, this code won't compile because depreciation_value has no declared value.

``` cpp
// better code example
class Car {
    string model; // class type
    double value; // primitive type
    const double depreciation_value; // const member

    public:
    Car() : value(0.00), depreciation_value(0.10){}; // default constructor (no junk data)
};
```
 - The above code better initializes all variables by leaving no instances of junk data.
 - initalizing the string in this case is optional, given it will automatically obtain a empty string as a class member.

## Class Variables (Static Member Variables)
    A special data member that is shared by all instances (objects) of a class. Kind of like global variables.

    There is only one copy of the static variable for the entire class, regardless of how many objects are created.
