# [Classes and Objects]
### Definition
 - Classes: A class is a user-defined data type that serves as a blueprint or template within a program's code.
 - Objects: An object is a specific instance of a class created by the program.

### Why it matters
 Classes are fundamental to object-oriented programing (OOP), allowing developers to group related data and functions into a single, organized unit. Essentially, it's not OOP unless you have classes and objects.

### Common Mistakes
 1. Classes and objects are not the same. Classes are the structure that defines an object. An object is the instance of a class.
 2. C++ also supports a similar feature to classes called structs, or structures. In modern day, classes and structs are just about the same thing, with the only difference being default access level.
   - Structs are public by default.
   - Classes are private by default.
