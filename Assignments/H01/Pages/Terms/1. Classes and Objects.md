# Classes and Objects
### Definition
 - Classes: A class is a user-defined data type that serves as a blueprint or template within a program's code.
 - Objects: An object is a specific instance of a class created by the program.

### Why It Matters
 Classes are fundamental to object-oriented programing (OOP), allowing developers to group related data and functions into a single, organized unit. Essentially, it's not OOP unless you have classes and objects.

### Code Example
``` cpp
#include <iostream>
#include <string>
using namespace std;

// Define a class called "Car"
class Car {
private: // classes are private by default, but for readability including a private header is useful.
    string brand;
    string model;
    int year;

public:
    Car() = default; // default constructor that c++ will automatically make.

    // Constructor to initialize a Car object
    Car(string b, string m, int y) {
        brand = b;
        model = m;
        year = y;
    }

    // Member function to display car details
    void displayInfo() {
        cout << "Brand: " << brand << ", Model: " << model << ", Year: " << year << endl;
    }

    // Member function to set a new year
    void setYear(int y) {
        year = y;
    }

    // Member function to get the year
    int getYear() {
        return year;
    }
};

int main() {
    // Create objects of the class Car
    Car car1("Toyota", "Corolla", 2020);
    Car car2("Honda", "Civic", 2019);

    // Access member functions using objects
    car1.displayInfo();
    car2.displayInfo();

    // Modify car2's year using a member function
    car2.setYear(2021);
    cout << "After updating the year:" << endl;
    car2.displayInfo();

    return 0;
}
```

### Common Mistakes
1. Classes and objects are not the same. Classes are the structure that defines an object. An object is the instance of a class.

2. C++ also supports a similar feature to classes called structs, or structures. In modern day, classes and structs are just about the same thing, with the only difference being default access level. Structs are public by default. Classes are private by default.

3. All classes need a class definition. This includes:
   - The class keyword
   - User-defined class name (or identifier)
   - Class body enclosed in curly braces
   - A semicolon after the closing brace

4. Some options not needed to run, but reccomended for a class definition:
   - Data Members (variables)
   - Member Functions (getters/setters)
   - Constructor (at least a specified default one)
   - Destructor (cleanup)
